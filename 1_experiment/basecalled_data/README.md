# Basecalled Data

Pointers to the `sequencing_summary` files (and BAM outputs) for each cohort on Turbo.

These files are produced by the dorado commands in [`../dorado_commands.md`](../dorado_commands.md).

> The figure script reads end reasons directly from POD5 files and joins read
> lengths / Q-scores from `sequencing_summary` by `read_id`. Both inputs are
> required to reproduce the figure.
